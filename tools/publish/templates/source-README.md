# must5src · 五子棋训练与构建源码

[浏览器在线试玩](https://risc.ink/must5/) · [网页发布仓库](https://github.com/732857315/must5)

本仓库提供两个 5×5 RGB U-Net、全盘策略网络、训练数据与增广、棋盘规则、搜索、浏览器导出和相关测试。固定输入、初始权重和发布权重随仓库提供，复现不依赖原开发电脑的 D 盘目录或私人对局文件。

**从 [REPRODUCE.md](REPRODUCE.md) 开始**：安装固定依赖、校验输入，使用全新目录训练并比较参数，或从已发布权重构建网页。完整复现的实测开发环境是 Windows x64；训练数据生成包含限时搜索，因此固定数据训练与重新生成数据分别说明，不承诺不同设备得到完全一致的限时搜索数据。

网页端在访问者浏览器中运行，支持手机和电脑。默认 15×15，行列可分别设置为 5–32；默认每步 1 秒。当前模型尚未通过“先手千局无负”等目标验收。

本仓库不包含浏览器缓存、截图、个人棋局、临时日志和全部历史实验。复现必需的少量来源棋谱与证明属于固定训练输入，保留其原始内容和 SHA-256。
