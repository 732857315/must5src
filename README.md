# must5src · 五子棋训练与构建源码

[浏览器在线试玩](https://risc.ink/must5/) · [网页发布仓库](https://github.com/732857315/must5)

本仓库提供两个 5×5 RGB U-Net、全盘策略网络、训练数据与增广、棋盘规则、搜索、浏览器导出和相关测试。固定输入、初始权重和发布权重随仓库提供，复现不依赖原开发电脑的 D 盘目录或私人对局文件。

**从 [REPRODUCE.md](REPRODUCE.md) 开始**：安装固定依赖、校验输入，使用全新目录训练并比较参数，或从已发布权重构建网页。完整复现的实测开发环境是 Windows x64；训练数据生成包含限时搜索，因此固定数据训练与重新生成数据分别说明，不承诺不同设备得到完全一致的限时搜索数据。

网页端在访问者浏览器中运行，支持手机和电脑。默认 15×15，行列可分别设置为 5–32；默认每步 1 秒。当前模型尚未通过“先手千局无负”等目标验收。

网页默认只显示棋子，落点参考可按需开启；禁下设置与分析详情折叠收纳。棋盘显示双方执棋、当前回合与手数，支持方向键选点和 Enter 落子。人类回合的后台提示计算不阻止落子，新开对局前会确认。顶部 GitHub 入口与“开源与帮助”区可直达源码仓库、网页仓库和使用文档。

本仓库不包含浏览器缓存、截图、个人棋局、临时日志和全部历史实验。复现必需的少量来源棋谱与证明属于固定训练输入，保留其原始内容和 SHA-256。

## 构建与重新部署

按 [REPRODUCE.md](REPRODUCE.md) 配置环境后，运行 `npm ci` 和 `npm run build:browser`，从随仓库提供的发布权重生成静态网站。完整的测试、离线检查、发布包校验和线上验证命令见 [部署说明](web/browser/DEPLOY.md)。源码变更保存在本仓库，校验后的网页资源发布到 `must5`；训练输入和开发环境不进入网页发布包。

网页在棋盘尺寸不变时复用格子节点；只保留两个局部和最近使用的两个全局推理会话。离线缓存按部署目录隔离，完整模型文件仍支持所有棋盘尺寸。旧 ncnn 演示按需加载可选依赖，不影响 U-Net 训练入口。发布脚本直接使用根目录说明和许可证，避免维护重复模板。

## 搜索棋力对照

主搜索按落子增量维护棋形，并在单次请求内缓存相同局面的搜索结果，让相同预算覆盖更深的变化。缓存的估值不作为必胜或安全证明；独立威胁验证仍决定证明状态。网络权重、候选宽度和每步时间设置保持原值。

2026-09-26 在同一台电脑的真实 Edge Worker 中，以 15×15、每步 1 秒与旧网页版本 `04fbc4d57176c0c87229` 对弈。固定开局交换先后手：种子 `20260926` 的 4 组为 6 胜 2 负；未参与调整的种子 `20261003` 的 6 组为 8 胜 4 负。共 20 局全部走至终局，新版 14 胜 6 负。这是小样本旧版对照，不代表对人类的胜率或千局棋力验收，也不表示网络已重新训练。

保留旧版完整网页目录（含 `assets.json`）后，可复测两个构建。工具校验并冻结双方资源，记录每手搜索结果、网络偏好和完整棋谱，拒绝覆盖已有输出：

```powershell
python tools/browser/strength_bench.py --baseline path/to/old-browser --output exports/strength/run-a --pairs 4 --seed 20260926
python tools/browser/strength_bench.py --baseline path/to/old-browser --output exports/strength/run-b --pairs 6 --seed 20261003 --skip-probes
```
